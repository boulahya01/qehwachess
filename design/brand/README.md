# The Shared Cup

Approved Qehwa Chess identity: a top-down coffee cup centered on four chessboard squares, in deep jade, ivory, and charcoal.

The original supplied artwork and export pack are preserved in this directory. The website serves only `public/qehwa-chess.svg` and `public/apple-touch-icon.png`; presentation images and the source archive are not copied into the deployed public folder.

The SVG is used unchanged in the header, footer, and favicon. The 256px square PNG is used as the touch icon. Integration is separate from the future production-domain and OAuth branding verification.
